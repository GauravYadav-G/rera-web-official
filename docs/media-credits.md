# RERA WEB demo media and source permissions

## Patch / RW — 01

Patch is an original RERA WEB character modeled for this site. `scripts/render-patch.py` produces the ceramic-and-graphite geometry, transparent still, sixteen turntable angles, and studio film. The optional studio light is [Studio Small 08](https://polyhaven.com/a/studio_small_08) by Sergej Majboroda / Poly Haven, released under [CC0](https://polyhaven.com/license). It is baked into the lighting and is not sent to site visitors as a large environment file. The web uses a compressed portrait and a lazy-loaded sprite of real 3D renders without WebGL. No game character, marks, or game footage is used.
